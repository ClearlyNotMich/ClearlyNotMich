## Selected projects

### [UvA–HvA Agentic Tools](https://github.com/ClearlyNotMich/uva-hva-agentic-tools)

The maintained project is [UvA/UvA-HvA-Agentic-Tools](https://github.com/uva/UvA-HvA-Agentic-Tools); this repository preserves earlier development work. I contributed model discovery, provider routing, interactive configuration and background-poll response handling to its TypeScript integration for the Pi coding agent. The implementation also reconciles streaming events with final response output.

**Focus:** TypeScript · AI tooling · API integration

### [Evolutionary Computing — Team 20](https://github.com/ClearlyNotMich/EvolutionaryComputing2026-team20)

Master's team coursework on robot-body and neural-controller evolution in simulation, built on ARIEL and MuJoCo. My contributions include subtree crossover, survivor-selection refinements, dashboard genotype support, tests and parallel evaluation. The repository includes saved experiments and analysis tools.

**Focus:** Python · Evolutionary algorithms · Robot simulation

### [Fabric Identification with Computer Vision](https://github.com/ClearlyNotMich/AI-DrivenClothPropertiesDetection)

Contributed VGG19 transfer-learning experiments to a team project identifying fabrics from close-up photographs. The repository includes research notebooks, non-destructive image tiling and a fabric metadata demo. It is a research prototype; the full training dataset and trained weights are not bundled.

**Focus:** TensorFlow/Keras · Transfer learning · Image preparation

### [HMI — Speech and Vision](https://github.com/ClearlyNotMich/HMI)

Coursework combining SpeechBrain transcription evaluation with OpenCV face detection and EigenFace recognition. The command-line workflows include word error rate scoring, annotation validation and explicit training/demo entry points, with offline tests using synthetic inputs and test doubles.

**Focus:** Python · Speech recognition · Computer vision · Evaluation

### [Pepper Robot Interaction Prototype](https://github.com/ClearlyNotMich/Pepper-Robot-COVID-19-Mask-Detection)

Collaborative coursework connecting Pepper's NAOqi interfaces, MQTT messaging, a tablet UI and an ESP8266 light sensor. The prototype explores greetings, face tracking and navigation, with offline configuration and lifecycle checks. Hardware operation requires a compatible supervised lab setup.

**Focus:** Robotics integration · Python · MQTT · Embedded systems

### [Robot Companion Prototype](https://github.com/ClearlyNotMich/Quadruple-Robot-Dog-Companion)

Controller scaffolding, asynchronous logging and a standalone LiDAR mapping demo adapted from Simon D. Levy's BreezySLAM example. The mapping helper adds explicit configuration, device cleanup and tests with simulated devices. The integrated robot remains a scaffold.

**Focus:** Python · LiDAR mapping · Resource management · Testing
